# Student Performance Analysis

A beginner-friendly data analysis project using Python and Pandas.

## 📊 Project Overview

This project analyzes student academic performance based on:

- Mathematics marks
- Python marks
- English marks
- Attendance

## 🛠️ Technologies Used

- Python
- Pandas
- CSV

## 📈 Analysis Performed

The project calculates:

- Average marks for each student
- Average marks by subject
- Top 3 performing students
- Average attendance
- Highest-performing student

## 📁 Project Files

| File | Description |
|---|---|
| `students.csv` | Student performance dataset |
| `analysis.py` | Python analysis script |
| `README.md` | Project documentation |

## 🎯 Learning Goals

This project was created to practice basic data analysis concepts using Python and Pandas.
